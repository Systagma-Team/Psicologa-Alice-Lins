# Prompt inicial para Claude / Claude Code

Use a pasta `psychologist-behance-kit/` como referência visual e de implementação para criar o site de um profissional de psicologia.

Antes de escrever código:
1. leia o `CLAUDE.md` e todos os arquivos indicados nele;
2. verifique se `assets/downloaded/` possui as cinco pranchas do Behance;
3. se não possuir, execute o script de download correspondente ao sistema operacional;
4. inspecione visualmente todas as pranchas;
5. analise o projeto atual, stack, componentes e sistema de estilos;
6. apresente um plano de implementação.

As pranchas do Behance são a autoridade visual. Os tokens do kit foram reconstruídos e devem ser ajustados se divergirem das imagens.

Não invente nome, CRP, formação, abordagem, depoimentos, número de pacientes, avaliações, serviços ou resultados clínicos. Use placeholders claros para toda informação ainda não fornecida.

Depois da análise, implemente de forma incremental e responsiva, reutilizando a arquitetura existente do projeto sempre que possível.
