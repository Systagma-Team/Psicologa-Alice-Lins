# Accessibility Checklist

- Contraste de texto compatível com WCAG AA.
- Tamanho base recomendado: 16px ou maior.
- Corpo de texto com line-height confortável (1.5–1.75).
- Labels visíveis nos campos; placeholder não substitui label.
- Focus visible em links, botões e inputs.
- Alvos de toque de aproximadamente 44px ou mais.
- `prefers-reduced-motion` para reduzir animações.
- Texto alternativo real para a foto profissional.
- Não usar somente cor para indicar erro ou seleção.
- Mensagens de erro devem explicar como corrigir.
- Navegação completa por teclado.
- Headings em hierarquia sem saltos arbitrários.
- CTA não deve depender apenas de ícone.
